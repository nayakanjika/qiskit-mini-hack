# Intermediate challenge: LiH qubit reduction

The GitHub-added Person 1 materials are kept together here:

- `p1_qubits.ipynb`: LiH baseline and qubit-reduction notebook.
- `p1_setup.py`: shared LiH model and resource-counting helpers.
- `p1_results.csv`: recorded resource and accuracy results.

Open the notebook with the repository root as the Jupyter working directory; it imports the helper as `intermediate_challenge.p1_setup`.
