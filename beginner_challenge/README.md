# Beginner challenge: HeH⁺ dissociation curve

Start with `challenge_1_tutorial qiskiteers.ipynb` for the single-geometry VQE introduction, then open `heh_plus_dissociation.ipynb` to scan bond lengths, estimate equilibrium and dissociation, and compare UCCSD/VQE with a particle-number-constrained exact reference.

The exercise uses PySCF with the minimal STO-3G basis, Jordan–Wigner mapping, Hartree–Fock + UCCSD, and a noiseless statevector estimator. Its equilibrium and dissociation values are therefore estimates within this model, not basis-set-limit or experimental values.
